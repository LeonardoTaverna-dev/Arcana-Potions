Fundada em 1693 no universo desta história, a Arcana preserva essências que desafiam as leis do mundo comum. Seus alquimistas acreditam que o poder mais raro é saber quando usá-lo.

Fora da história

Um projeto feito para aprender.

Arcana Potions é um projeto escolar de desenvolvimento web. A proposta reúne HTML semântico, CSS responsivo e JavaScript para criar uma experiência interativa com identidade própria.

A botica, sua data de fundação, as poções e os valores são inteiramente fictícios. A bolsa é apenas uma simulação local.
